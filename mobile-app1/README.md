TravelGuard AI Expo React Native app

Quick start

1. Install Expo CLI (if not installed):

```bash
npm install -g expo-cli
```

2. Install dependencies and start:

```bash
cd a=mon=bile-app
npm install
npm start
# or
expo start
```

This scaffold includes a simple `PANIC` button component in `App.js`. Next steps: integrate the backend API, add navigation, and wire authentication.
